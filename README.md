AI Workout Planner

It is an Android app for workout planning, where a user can create a workout plan with the help of an AI, depending on their fitness goal and level of expertise.

Features

The app will provide workout plans created by an AI with the help of the Google Gemini API.

The app will be created using the latest Android technology, Jetpack Compose.

The app will use the MVVM architecture for better maintenance, testability, and scalability.

The app will use Room database for local data storage, with full CRUD operations for workouts and exercises.

The app will provide a multi-screen interface for workout planning and tracking.

Tech Stack

Kotlin

Jetpack Compose

MVVM Architecture

Room Database

Retrofit

Google Gemini API

Architecture

The application will use the MVVM architecture style. This style is divided into the following layers:

UI Layer – This is where we will use screens created with the help of Jetpack Compose.

ViewModel Layer – This is where we will use view models for better maintenance, testability, and scalability.

Repository Layer – This is where we will use repositories for better maintenance, testability, and scalability.

Data Layer – database for local persistence
